A document scanning project is successful only when the final files are complete, readable, searchable and easy to retrieve. A high page count alone does not prove quality.

Whether you are scanning HR files, medical records, legal files or government archives, agree on quality checks before production starts. This avoids discovering missing pages or unusable OCR after the physical files have been returned.

## 1. Check page completeness

For each batch, verify that:

- Every file or folder received is accounted for
- Page counts match the source record or batch manifest
- Blank pages are handled according to the agreed rule
- Duplicate, missing and out-of-order pages are reported
- Attachments, inserts, folded pages and back sides are included
- File names or barcodes link the output to the correct source file

Keep a batch-level exception report. It should identify the file, page or image affected and the action taken.

## 2. Check image quality

Inspect samples and exception pages for crop, skew, blur, shadows, bleed-through, low contrast, noise and incorrect orientation. Old files, carbon copies, coloured forms and bound registers often need different scanner settings.

The quality sample should include the most difficult documents, not only clean A4 sheets. Review black-and-white, greyscale and colour outputs separately when the project uses more than one mode.

## 3. Validate OCR and searchability

Open a sample of searchable PDFs and test names, dates, reference numbers and other important fields. OCR should be checked against the image because a visually perfect scan can still have incorrect text.

For low-confidence text, handwriting, stamps and damaged pages, use an exception queue or manual review. Do not promise that OCR will read every document equally well without testing a representative sample first.

## 4. Validate metadata and indexing

Define mandatory fields before scanning begins. Depending on the record type, these may include:

- File or employee number
- Record or patient number
- Department, branch or location
- Document type and date
- Retention category or status
- Confidentiality or access group

Run completeness and format checks on the index. A searchable file is still difficult to use if its employee ID, case number or folder reference is missing.

## 5. Confirm delivery and security

Agree on the delivery format, naming convention, folder structure, encryption, access permissions, backup and handover log. For DMS, EMR, ERP or cloud migration, test-import a small batch before the full handover.
